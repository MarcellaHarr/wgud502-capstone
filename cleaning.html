Filter victims and recode victim and offender race

Now, I’ll narrow the homicide DF to female victims with a known race, using the filter() to keep the “Female” records in VicSex and drop the “Unknown” records in VicRace. Then, the mutate() with the case_when() to collapse the three smaller race groups, such as Asian, into one “Other Ethnic” group in victim_race_collapsed, and the if_else() turns that into a two-group victim_racial_construct: Black or Not Black. The result is saved as the recoded DF, and the nrow() and my custom three_col_check() confirm its size and categories.

# Recode victim race/ethnic into binary constructs.

#== victim side: filter gender, drop Unknown race, collapse categories, binary-encode ==
homicide_recoded <- homicide_renamed %>%
  filter(VicSex == "Female") %>%
  filter(VicRace != "Unknown") %>%
  mutate(
    # (Matt, 2020; Hadley, 2024)
    victim_race_collapsed = case_when(
      VicRace %in%
        c(
          "Asian",
          "American Indian or Alaskan Native",
          "Native Hawaiian or Pacific Islander"
        ) ~ "Other Ethnic",
      TRUE ~ VicRace # keeps "Black" and "White" as-is
    ),
    # (Hadley, 2024)
    victim_racial_construct = if_else(
      victim_race_collapsed == "Black",
      "Black",
      "Not Black"
    )
  )

#== view recode dataset record count ==
nrow(homicide_recoded)
[1] 197147
#== check recoded and original race constructs ==
# (Buck, 2025)
three_col_check(
  data = homicide_recoded,
  col1 = victim_race_collapsed,
  col2 = victim_racial_construct,
  col3 = VicEthnic
)

Finally, the left_join() matches the municipal DF to the deduplicated DF on city_match and state, followed by the same row-count and agency_population NA proportion checks.

# Deduplicated agency and municipal police subset join.

#== join subsets ==
municipal_joined <- homicide_municipal %>%
  left_join(
    geojson_municipal_dedup,
    by = c(
      "city_match" = "agency_city_match",
      "state" = "agency_state"
    )
  )

#== call the total rows function ==
# (Buck, 2025)
total_rows(
  `Duplicated DF Row n()` = homicide_municipal,
  `De-Duplicated DF Row n()` = municipal_joined
)

The municipal DF has 141,096 records, and the joined DF has 141,096, with no many-to-many warning this time. More importantly, the NA proportion is 0.1409962, or about 14.1%, down from about 84% before deduplicating, since rows without a population were dropped before the join, so a record now goes without one only when its city and state have no local police department row that has one.


To finish, I’ll save the modeling DF with arrow::write_parquet() as its own Parquet file in the processed data folder, separate from the final DF’s file. Then, I’ll read it back with arrow::read_parquet() and get its number of rows and columns with dim().

# Save the modeling dataset as a Parquet file.

#== write to data/processed folder ==
# (Olumide, 2025)
arrow::write_parquet(
  homicide_modeling_df,
  here::here(
    "data",
    "processed",
    "homicide_modeling.parquet"
  )
)

In conclusion, the saved file has 15,766 rows and 35 columns, one more than the 34 columns of the final DF, since it adds jurisdiction_match.
